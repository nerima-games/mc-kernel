# バージョニングと公開

このパッケージはセマンティックバージョニングに従います。

- `PATCH`: 挙動の修正。公開 API の削除・変更はしない。
- `MINOR`: 後方互換な API の追加。
- `MAJOR`: 公開 API の削除または非互換な変更。

公開前に `pnpm verify` を通し、変更した公開面は `pnpm api:update` でスナップショットに反映します。タグ `v*` の CI は
GitHub Packages への publish を実行します。consumer は公開済みの厳密なバージョンを依存に追加してから
ローカルの暫定ミラーを削除します。

未公開の package 名を consumer に先行して追加しません。ローカル解決と CI を壊さず、公開物を実際に
インストールしてから移行を開始するためです。
