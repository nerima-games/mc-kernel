# バージョニングと変更管理

このパッケージはセマンティックバージョニングに従います。

- `PATCH`: 挙動の修正。公開 API の削除・変更はしない。
- `MINOR`: 後方互換な API の追加。
- `MAJOR`: 公開 API の削除または非互換な変更。

変更前に `pnpm verify` を通し、変更した公開面は `pnpm api:update` でスナップショットに反映します。
パッケージ名とバージョンは API 契約を追跡するためのメタデータです。npm registry や GitHub Packages には公開しません。

consumer は独立して検証可能なローカル語彙を所有します。共有化が必要になった場合は、認証付き registry を
依存境界にせず、単一ワークスペースまたは Git submodule のような再現可能な統合方式を先に設計します。
